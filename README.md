# 华工杯 · 校园足球模拟器

一款以华中科技大学校园足球联赛为背景的网页文字生涯模拟游戏。

## 运行方式

项目是一个单文件网页游戏：

1. 双击 `index.html`。
2. 保持 `甲组球队logo`、`乙组球队logo` 与 `index.html` 在同一个目录。
3. 建议使用 Chrome、Edge 等现代浏览器。

## 在线游玩

## 主要系统

- 球员四维成长：能力、心态、关系、学业
- 新生杯、华工杯、毕业杯三大赛事
- 甲组、乙组升降级
- 队长、裁判、转专业、跨考、服役等生涯路径
- 受伤、红黄牌停赛、首发替补和校内舆论
- 比赛决策与系统模拟
- 成就与多结局
